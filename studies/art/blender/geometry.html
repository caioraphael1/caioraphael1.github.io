Mesh Tools

  • Extrude Manifold :

    • Blender Hub - Extrude Manifold showcase

  • Offset Edge Loop Cut :

    • It's a Bevel with Profile Shape of 1.0.

  • Rip Region .

    • "Clone vertex/edges and keep them disconnected, with the option to connect them".

    • Only works with vertex and edges.

    • Opens a region. This region can be filled in the tool configs.

    • The "filled" version of this tool kinda looks like an extrude, but a bit different.

    • Very useful.

    • Blender Axis - Rip Region showcase

  • PolyBuilder :

    • Extrude edges + Move Vertex, or shift click to remove edges, vertex or faces.

    • They are not very useful when comparing to just press E to extrude, or using some other solution for retopology.

  • Rip Edge :

    • For vertices: creates a new vertices from the selected vertices, which will most likely result in N-Gons.

    • For edges: creates bad geometry, simple.

    • For faces: it does nothing.

    • I don't find anything useful about this tool.
