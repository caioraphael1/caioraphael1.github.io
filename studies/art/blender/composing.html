Composing

🕒 Created: 2023-07-26 | Updated: 2026-11-12

  • Cody Gindy - Creating a bridge scene with dusk illumination

    • Beautiful.

  • Max Hay - Pillars with geometry nodes and composed scene

  • Max Hay - Dystopic snow scene walkthrough

    • Simple snow on object via normal direction.

    • General compositions tricks.

    • How to make chains with arrays, curves, etc.

  • Max Hay - Overgrown industrial complex

    • It basically uses the Arborea addon to get all the grass, foliage, etc.

  • linolafettatnet - "Spatial look" via compositing

  • Addon - Stack

    • (2026-10-25)

      • Just adds a node. Quite simple.

      • The node is just a chain of Mix Color nodes, that's all.

      • The node is not added to the compositor, only to the Node Editor.

      • The added node is not a node group, so you can't go inside of it.

  • Addon - Matalog

    • (2026-10-25)

      • It's just an addon for quick switch between materials. It's an addon for material navigation.

      • Clicking a material on the new sidepanel, selects the object(s) using that material, instead of the classic behavior of changing the material of the current selected object.

      • You can only change the text alignment in the configs.

  • Addon - Math Controller

  • Addon - LayerComp

    • (2026-10-25)

      • The UI is very buggy and very confusing.

      • I got "AI code" vibes.

      • Got some random python errors.

      • I don't think this helped at all the idea of using the compositor for image editing.

  • Addon - True Image Editor

    • Paid.

    • True Image Editor showcase

  • Addon - DOBLUX Button to execute Geometry Node Group

  • Addon - Node Wrangler

    • (2026-10-26)

      • Pros :

        • Add Reroute to Selected is good.

        • Texture setup is good.

        • Principled BSDF setup is good.

      • Cons :

        • Show in Output can be irrelevant when you have 'Node Peek'.

        • The align tools is very very basic; the 'Right-Angled Node Connection' is much better.

        • Reload Image is a bit irrelevant.

        • Issues :

          • The sidebar is a mess.

          • The keymaps setup is TERRIBLE. Every time the keymaps get reassigned and explodes my keymap preset.

  • Addon - Node Pie

  • Addon - Node Original Labels

    • Very useful. When a node has labels you get easily confused about it's original purpose, but this addon helps.

  • Addon - Node Peek

    • (2026-10-26)

      • Only works on the Shader Editor -> Object .

      • Very good, simple, and straight to the point.

      • Adds a few commands.

      • Adds automatically 1 shortcut: 'Pin Preview'.

      • Improvements :

        • I'd like the option for the previews to be repositioned.

        • I'd like the option to only show previews for pinned nodes.

  • Addon - Node Preview Thumbnails

    • (2026-10-26)

      • REALLY LAGGY. Crashes the app.

      • Just use Node Peek, it's not worth.

  • Addon - Node Void Keeper

    • Keeps your nodes centered around (0,0) automatically every time you save or load a file.

    • (2026-10-27)

      • Every time you save a file, the camera drifts, it's really annoying.

  • Addon - Right-Angled Node Connection

    • (2026-10-26)

      • It has a panel that gives the position and dimensions of the node.

      • Buttons for 'Right Angled Connection':

        • It doesn't create any reroutes, it uses the existing reroutes and tries to get them to align in right angles.

        • This means that the addon works best if the nodes were rerouted before.

      • Buttons for change the node width.

      • Buttons for many ways of aligning nodes together.

      • Button to set consistent spacing between nodes.

      • The addon does add any way to reroute nodes.

      • If you disable the 'Quick Access' in the configs, the shortcut visual goes away, which is nice.

  • Addon - Node Orthogonalizer

    • (2026-10-26)

      • Tree Layout gives a really weird result.

      • 'Automatic Squares' makes so that every time you move a node, the nodes are updated to be squared again. This doesn't give a good result, as you just end up with tons of reroutes, and this bugs the ctrl z sometimes.

      • Nah.

  • Addon - Node Editor Pro

    • (2026-10-27)

      • The tools don't really do anything. The node is obsolete in Blender 5.3.

      • The snap doesn't seem to do anything.

      • Nope.

  • Node Reroutes :

    • Either use the tool, or press shift + RMB.

    • Click and dragging will start a new connection.

    • Use G to move the new node Reroute.

  • Node Repeat :

    • What ever you add as the input, it shows as the output.

    • Blender - Node Repeat demo

  • Node Closure :

    • It's a function, that has access to non-local parameters.

    • This is only useful when you consider a node group asking for a "function pointer", to perform its operation.

    • Harry Blends - Closure Nodes

  • Node Menu Switch :

    • Graffinity3D - Node Menu Switch demo
