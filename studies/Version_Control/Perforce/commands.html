Commands

🕒 Created: 2026-05-20 | Updated: 2026-06-04

  • Clone a repository:

    • Git: git clone <repo-url>

    • Perforce: There is no direct "clone" command. You create a workspace in P4V and synchronize files using p4 sync .

  • Add files:

    • Git: git add <file>

    • Perforce: p4 add <file>

  • Submit changes:

    • Git: git commit -m "message"  followed by git push

    • Perforce: p4 submit

  • Update the workspace with the latest changes:

    • Git: git pull

    • Perforce: p4 sync

  • Check the status of changes:

    • Git: git status

    • Perforce: p4 opened

  • Revert changes:

    • Git: git checkout -- <file>

    • Perforce: p4 revert <file>
