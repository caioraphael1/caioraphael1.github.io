🕒 Created: 2023-07-26 | Updated: 2026-11-12

  • Blender Docs - Geometry Nodes Fields

  • Blender Docs - Using Geometry Nodes to create Tools

Sockets

Rectangle

  • Rigid. Single values only.

  • ALL nodes in Inputs -> Constants  have only Rectangle outputs.

Circle

  • Versatile.

Diamond

  • Field.

  • Can go into:

    • Circle.

    • Diamond.

  • Can't go into:

    • Rectangle.

  • ALL nodes in Geometry -> Read  have only Diamond outputs.

Lines

Solid Line

  • Not carrying a field.

Dashed Line

  • Carrying a field.

  • Can't go into:

    • Rectangle.

  • Why am I getting a Dashed Line when all inputs are Circles??

    • Some nodes have things hiddenly assigned in their input nodes by default, if nothing is assigned. Sometimes, what is hiddenly assigned as a default input is actually a node with a Diamond.

    • Example:

      • Random Value Node:

        • All inputs and outputs are Circles.

        • The 'ID Input' is hiddenly assigned as 'ID Node', which outputs a Diamond.

        • Blender Docs - Random Value Node

        • Blender Docs - ID Node

Objects

Self Object Node

  • Blender Docs - Self Object Node

Object Info Node

  • Blender Docs - Object Info Node

    • Transform Space

      • Only changes Location , Rotation , Scale ; doesn't change the Geometry  input

      • Original:

        • The transform of this object, as shown in the Properties -> Object -> Transform  of that object.~

        • The global transform of this object.

      • Relative:

        • The transform of this object, relative to the current object that contains the Geometry Nodes modifier.

    • As Instance

      • Output the entire object as single instance instead of realized geometry. This allows instancing non-geometry object types, because the output will contain an instance of the object.

Geometry

  • Every transformation, position, rotation, scale, is relative to the origin of the object! Consider this is the vertex input, before applying the object transform.

Transform Geometry Node

  • Translation:

    • Translation relative to the origin of the object.

    • Direction :

      • The axis  is local to the object!! This means that moving in the Z-axis here, might not move up and down, as it depends on how the object is rotated!!!

    • Quantity :

      • (0, 0, 1)  might not mean "1 unit up", a it depends on the scale  of the object.

        • If the scale is 2, then instead of moving 1 unit, it moves 2 units.

Set Position Node

  • The position is the position relative to the origin of the object.

  • Can move individual vertex in the geometry.

Output

Viewer Node

  • Blender Docs - Viewer Node

    • Allows viewing data from inside a geometry node group in both the Spreadsheet Editor  and the 3D Viewport .

    • Enabling :

      • Click on the TV Icon on the header of the node, to enable or disable it.

      • Or, just click on a disabled Viewer Node.

    • To view in 3D :

      • Connect (Group Input | out: Geometry) -> (Viewer | in) .
