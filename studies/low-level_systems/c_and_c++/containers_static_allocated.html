Containers: Static Allocated

🕒 Created: 2023-10-11 | Updated: 2026-11-24

std::array  ( <array> ) (C++11)

  • Fixed-size wrapper over arrays.

  • No heap allocation.

  • Why not C arrays :

    • Arrays from C restrict its copy and easily decay into pointers, they probably suffer from an excess of optimization.

    • Unlike C arrays, std::array  can be copied and returned from functions.

Implementation

  • The storage is conceptually almost equivalent to: 

struct {
    int elems[4];
};

  • So: 

sizeof(std::array<int, 4>) == sizeof(int) * 4

  • On essentially every implementation.

  • LLVM libcxx - <array>

  • Conceptually: 

template<typename T, std::size_t N>
struct array {
    // Access: `a[i]`
    constexpr       T& operator[](std::size_t pos)       noexcept;
    constexpr const T& operator[](std::size_t pos) const noexcept;

    // Access: `a.at(i)`
    constexpr       T& at(std::size_t pos);
    constexpr const T& at(std::size_t pos) const;

    // Access: `a.front(i)`
    constexpr       T& front()       noexcept;
    constexpr const T& front() const noexcept;

    // Access: `a.back(i)`
    constexpr       T& back()       noexcept;
    constexpr const T& back() const noexcept;

    // Access: `a.data(i)`
    constexpr       T* data()       noexcept;
    constexpr const T* data() const noexcept;

    // Iterator: `a.begin()`
    constexpr       T* begin()       noexcept;
    constexpr const T* begin() const noexcept;

    // Iterator: `a.end()`
    constexpr       T* end()       noexcept;
    constexpr const T* end() const noexcept;

    // Info
    constexpr std::size_t size()     const noexcept;
    constexpr bool        empty()    const noexcept;
    constexpr std::size_t max_size() const noexcept;

    // Operations
    constexpr void fill(const T& value);
    constexpr void swap(array& other) noexcept;

    // Underlying storage
    T elements[N];
};

Initialization 

std::array<int, 4> a = {10, 20, 30, 40};

std::array<int, 4> a;
a = { 10, 20, 30, 40 }

  • a = other

    • Copy contents

Accessing elements

  • a[i]

    • Returns T& .

    • Access element.

    • Error handling :

      • NOT BOUND CHECKED .

      • Out-of-bounds (OOB) is undefined behavior (UB).

  • a.at(i)

    • Returns T& .

    • Access element

    • Error handling :

      • Out-of-bounds throws std::out_of_range .

  • std::get<N>(a);

    • Returns T& .

    • N  is a comptime index.

    • Error handling :

      • Out-of-bounds gives a compilation error.

  • a.front()

    • Returns T& .

    • First element.

  • a.back()

    • Returns T& .

    • Last element.

  • a.data()

    • Returns T* ; being a pointer to the first element (raw C array).

    • Pointer to underlying storage.

Info

  • a.size()

    • Number of elements (N)

  • a.empty()

    • Returns bool .

    • Always false if N > 0

  • a.max_size()

    • Maximum element count

Operations

  • a.fill(value)

    • Set every element to value

  • a.swap(other)

    • Swap contents

Operations: Iteration

  • a.begin()

    • Returns iterator  or const_iterator .

    • Iterator to first element.

  • a.end()

    • Returns iterator  or const_iterator .

    • Iterator past last element.

  • a.cbegin()  / a.cend()

    • Returns const_iterator .

    • Const iterators.

  • a.rbegin()  / a.rend()

    • Returns reverse_iterator .

    • Reverse iterators.

  • a.crbegin()  / a.crend()

    • Returns const_reverse_iterator .

    • Const reverse iterators.

std::span  ( <span> ) (C++20)

  • Non-owning view over contiguous memory.

    • Seems just like Odin's slices.

  • No memory allocation.

  • Modifying a span's elements modifies the original memory. A span does not own or destroy its elements. 

#include <span>

void Process(std::span<int> data)
{
    for (int v : data)
        printf("%d\n", v);
}

int arr[4] = {1,2,3,4};

Process(arr);

Implementation

  • LLVM libcxx - <span>

  • Conceptually: 

template<typename T, std::size_t Extent = std::dynamic_extent>
class span {
public:
    // Access: `a[i]`
    constexpr T& operator[](std::size_t pos) const noexcept;

    // Access: `a.front(i)`
    constexpr T& front() noexcept;

    // Access: `a.back(i)`
    constexpr T& back()  noexcept;

    // Access: `a.data(i)`
    constexpr T* data()  noexcept;

    // Capacity
    constexpr std::size_t size() const noexcept;
    constexpr std::size_t size_bytes() const noexcept;
    constexpr bool empty() const noexcept;

    // Subviews
    template<std::size_t Count>
    constexpr span<T, Count> first() const;

    constexpr span<T, std::dynamic_extent>
    first(std::size_t count) const;

    template<std::size_t Count>
    constexpr span<T, Count> last() const;

    constexpr span<T, std::dynamic_extent>
    last(std::size_t count) const;

    template<std::size_t Offset, std::size_t Count = std::dynamic_extent>
    constexpr auto subspan() const;

    constexpr span<T, std::dynamic_extent>
    subspan(std::size_t offset,
            std::size_t count = std::dynamic_extent) const;

private:
    // Conceptual representation:
    T* data;
    std::size_t size;
};

Initialization

  • Requires storage from elsewhere. 

int data[] = {10, 20, 30, 40};
std::span<int> s(data);

Accessing elements

  • a[i]

    • Returns T& .

    • Access element.

    • Error handling :

      • NOT BOUND CHECKED .

      • Out-of-bounds (OOB) is undefined behavior (UB).

  • a.at(i)  (C++26)

    • Returns T& .

    • Only in C++26.

    • Access element.

    • Error handling :

      • Out-of-bounds throws std::out_of_range .

  • a.front()

    • Returns T& .

    • First element.

  • a.back()

    • Returns T& .

    • Last element.

  • a.data()

    • Returns T* .

    • Pointer to underlying storage.

  • s.first(n)

    • Returns constexpr span<element_type, n>

    • View first n elements

  • s.last(n)

    • Returns constexpr span<element_type, n>

    • View last n elements

  • s.subspan(offset)

    • Returns constexpr span<element_type, n>

    • View from offset to end

  • s.subspan(offset, count)

    • Returns constexpr span<element_type, n>

    • View a specific range

Info

  • s.size()

    • Number of elements

  • s.size_bytes()

    • Total size in bytes

  • s.empty()

    • Whether size is zero

Operations: Iteration

  • s.begin()

    • Returns iterator  or const_iterator .

    • Iterator to first element.

  • s.end()

    • Returns iterator  or const_iterator .

    • Iterator past last element.

  • s.cbegin()  / s.cend()

    • Returns const_iterator .

    • Const iterators.

  • s.rbegin()  / s.rend()

    • Returns reverse_iterator .

    • Reverse iterators.

  • s.crbegin()  / s.crend()

    • Returns const_reverse_iterator .

    • Const reverse iterators.

std::string_view  ( <string_view> ) (C++17)

  • std::string_view

    • Not-owning view of memory. No allocation.

    • Read-only slice of a string.

    • More focused on string operations.

    • It's just std::basic_string_view<char> .

  • std::span<char>

    • Not-owning view of memory. No allocation.

    • Can modify the elements.

    • More focused on array operations.

  • Example: 

    #include <string>
#include <string_view>

void process(std::string_view text) {
    // Read text without copying it.
}

int main() {
    std::string s = "hello";
    process(s);
    process("world");
}

std::pair  ( <utility> ) (C++98)

  • No heap allocation.

  • Only 2 values.

Implementation 

template<typename A, typename B>
struct Pair {
    A first;
    B second;
};

Initialization 

std::pair<int, float> p = {10, 3.14f};

std::pair<int, float> p;
p = {10, 3.14f}

Accessing elements

  • p.first

    • Returns the first  value.

    • copy vs reference is defined by what's assigned to.

  • p.second

    • Returns the second value.

    • copy vs reference is defined by what's assigned to.

  • auto [a, b] = p;  (C++17)

    • Returns a copy  of the pair.

      • Ex: a = 50;  does NOT modify p.first .

    • a  is .first  and b  is .second  via Structured Bindings.

  • auto& [a, b] = p;  (C++17)

    • Returns a reference  of the pair.

      • Ex: a = 50;  does modify p.first .

    • a  is .first  and b  is .second  via Structured Bindings.

  • const auto& [a, b] = p;  (C++17)

    • Returns a const reference  of the pair.

      • Ex: a = 50;  gives an error, as a  is const .

    • a  is .first  and b  is .second  via Structured Bindings.

  • std::get<N>(p);

    • Returns T& .

    • N  is a comptime index.

    • Error handling :

      • Out-of-bounds gives a compilation error.

  • std::get<T>(t)  (C++14)

    • T  is a type.

    • All errors are compilation errors.

    • Ex: 

      std::pair<int, int> p = {10, 20};

std::get<int>(p);   // Compilation error: ambiguous
std::get<float>(p); // Compilation error: type not found

Operations

  • p.swap(other)

    • Swap contents

std::tuple  ( <tuple> ) (C++11)

  • Does not heap allocate.

  • Many values.

Initialization 

std::tuple<int, float, const char*> t = {
    10, 3.14f, "hello"
};

  • std::make_tuple(...)

    • Construct tuple

  • std::tie(a, b, c)

    • Create tuple of references

Accessing elements

  • No public methods.

  • auto [a, b] = t;  (C++17)

    • Returns a copy  of the pair.

      • Ex: a = 50;  does NOT modify std::get<0>(t) .

    • a  is .first  and b  is .second  via Structured Bindings.

  • auto& [a, b] = t;  (C++17)

    • Returns a reference  of the pair.

      • Ex: a = 50;  does modify std::get<0>(t) .

    • a  is .first  and b  is .second  via Structured Bindings.

  • const auto& [a, b] = t;  (C++17)

    • Returns a const reference  of the pair.

      • Ex: a = 50;  gives an error, as a  is const .

    • a  is .first  and b  is .second  via Structured Bindings.

  • std::get<N>(t)

    • Returns T& .

    • N  is a comptime index.

    • Error handling :

      • Out-of-bounds gives a compilation error.

  • std::get<T>(t)  (C++14)

    • T  is a type.

    • All errors are compilation errors.

    • Ex: 

      std::tuple<int, int, bool> t = {10, 20, false};

std::get<bool>(t);  // Ok
std::get<int>(t);   // Compilation error: ambiguous
std::get<float>(t); // Compilation error: type not found

Info

  • std::tuple_size<T>::value

    • Number of elements

  • std::tuple_element<I, T>::type

    • Type of element I

Operations

  • std::tuple_cat(a, b)

    • Concatenate tuples

  • std::swap(a, b)

    • Swap tuples

  • std::apply(func, t)

    • Call function with tuple elements (C++17)
