C++

  • Verify the default C version, if you don't specify during compilation:

    • Windows: cmd /c "clang -dM -E - < nul | findstr __STDC_VERSION__"

      • (2026-04-01) The default is C17.

  • Versions .

C++98

  • Start of the language.

C++03

  • Basically just bug fixes and clarification revision of C++98.

  • The next version is C++11.

C++11

  • First usable version of the language.

  • Brings a major modernization and is one of the releases that most changed the language.

    .

    .

C++14

  • [[deprecated]]

  • Relaxed restrictions on constexpr  function bodies, allowing local variables, loops, and more complex control flow.

  • Lambdas can now be generic 

    auto fn = [](auto x) { return x * 2; };

  • Variable templates 

    template<typename T>
constexpr T pi = T(3.141592653589793);

  • Return type deduction with auto 

    auto add(int a, int b) {
    return a + b;
}

  • Binary literals 

    int flags = 0b1010;

  • Digit separators 

    constexpr auto value = 1'000'000;

C

C89/C90

  • Original ANSI/ISO C standard.

C99

  • Added inline , //  comments, variable-length arrays, and more standard headers.

C11

  • Introduced multithreading ( <threads.h> ), _Atomic , and optional bounds checking.

  • C11 .

C17

  • Bug-fix revision of C11, no major new features.

C23

  • Adds UTF-8 literals, improved enums, and more modern conveniences.
