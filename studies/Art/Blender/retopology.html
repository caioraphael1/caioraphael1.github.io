Manual

  • Knife Project Command

    • This is an amazing tool that can be used for lots of thinks, not only retopology.

    • How :

      1. Prepare the cutter by deleting it's faces, via select all -> Delete -> Only Faces .

      2. Enter Edit Mode selecting only the object (or objects) that will be cut.

      3. Hold shift and select the cutter in the Outliner.

      4. Align the view how you want the cut to be made. Orthographic view can be useful in this case. The cutter should be in front of the object that will be cut.

      5. Mesh -> Knife Project  or search for Knife Project .

      6. You can check 'Cut Through' after the fact, if you want.

    • 3D Learning Channel - How to use the Knife Project

    • Blender Secrets - Knife Project

    • Free, core.

    • The extension is actually quite insignificant. It just adds "better" behavior for when selecting a single vertex, basically. "fill add" and the rest of the behavior is basically the same.

    • The Addon is not worth while, imo.

    • I don't like this tool. Check the Mesh Tool section for explanations.
