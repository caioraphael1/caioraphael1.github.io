Camera Positioning

By using the vanishing points of an image

  • FSpy  / Addon - FSpy Blender Importer

    • Number of Vanishing Points:

      • Each axis should be perpendicular to the other ones in the world: Y vs X vs Z.

      • Lines of the same color should never  be parallel.

      • If using 1 vanishing point:

        • You generally cannot uniquely determine both the focal length and the physical sensor size from a single image alone.

        • Camera Data / Sensor:

          • The physical dimensions of the camera's imaging sensor.

        • Focal Length:

          • A physical property of the lens.

    • Reference Distance:

      • .

    • Principal Point:

      • Imagine a ray going straight through the middle of a camera’s lens. The point where this ray hits the sensor (or film) is the principal point. This point usually coincides with the midpoint of the image. In some cases, for example if an image has been asymmetrically cropped, the principal point might be somewhere else. If the position is known, select manual from the principal point menu and drag the yellow control point to the position of the principal point.

Camera vs Viewport

  • "The camera's focal length and sensor size both affect the FOV, so instead of reducing the camera's focal length from 50mm to 25mm, you can increase its sensor size from 36mm to 72mm."

    • 36mm results in the captured camera area being 50% of the screen’s work area/viewport. Simply double the camera’s sensor size to 72mm to make the camera view capture the full screen’s work area.
