Effects Framework (Legacy)

🕒 Created: 2026-11-24 | Updated: 2026-11-24

technique

  • A collection of rendering passes representing one way to render something.

pass

  • The pipeline state necessary for one rendering operation.

  • It does not execute a draw call. It configures the GPU pipeline.

  • The application still issues the actual draw call.

  • Specifies:

    • Which shaders should be bound.

    • Blend state.

    • Depth/stencil state.

    • Rasterizer state.

    • Render targets.

    • Other pipeline state supported by the Effects Framework version.

FX9 (Direct3D 9)

  • Introduced with the Direct3D 9 generation, circa 2002–2003.

  • Profiles:

    • Effect profiles:

      • fx_1_0

      • fx_2_0

    • Shader targets:

      • Vertex: vs_1_1 , vs_2_0 , vs_3_0 .

      • Pixel:   ps_1_x , ps_2_0 , ps_3_0 .

Shader

  • You directly assign pipeline states using Effect-specific state assignment syntax.

  • Example: 

    technique MyTechnique
{
    pass P0
    {
        VertexShader = compile vs_3_0 VSMain();
        PixelShader  = compile ps_3_0 PSMain();

        ZEnable = TRUE;
        ZWriteEnable = TRUE;
        AlphaBlendEnable = FALSE;
    }
}
Executing

  • Begin()

    • Activates the selected technique.

  • BeginPass()

    • Activates a pass.

  • CommitChanges()

    • Applies parameter changes made while a pass is active.

    • Only necessary when effect parameters change after a pass has started and those changes need to reach the device before drawing

  • EndPass()

    • Ends the active pass.

  • End()

    • Ends the technique.

  • Example: 

    UINT passes = 0;

effect->Begin(&passes, 0);

for (UINT i = 0; i < passes; ++i)
{
    effect->BeginPass(i);

    mesh->DrawSubset(0);

    effect->EndPass();
}

effect->End();

FX10 (Direct3D 10)

  • Introduced with Direct3D 10, circa 2006.

  • Profiles:

    • Effect profiles:

      • fx_4_0

      • fx_4_1

    • Shader targets:

      • SM4.0 : vs_4_0 , gs_4_0 , ps_4_0 .

      • SM4.1 : vs_4_1 , gs_4_1 , ps_4_1 .

Shader

  • Instead of assigning pipeline states directly, the Effects Framework exposes state-setting functions: 

    SetVertexShader(...);
SetPixelShader(...);
SetGeometryShader(...);
SetRasterizerState(...);
SetBlendState(...);
SetDepthStencilState(...);

  • Example: 

    technique10 MyTechnique
{
    pass P0
    {
        SetVertexShader(
            CompileShader(vs_4_0, VSMain())
        );

        SetPixelShader(
            CompileShader(ps_4_0, PSMain())
        );

        SetGeometryShader(NULL);
    }
}
Executing

  • There is no need for BeginPass()  or EndPass() .

  • The Apply()  operation applies the pass's states to the Direct3D device.

  • The application then issues the draw call.

  • Example: 

    technique->GetPassByIndex(i)->Apply(0);

context->DrawIndexed(indexCount, 0, 0);

FX11 (Direct3D 11)

  • Introduced with Direct3D 11, circa 2009.

  • Profiles:

    • Effect profile:

      • fx_5_0

    • Shader targets:

      • SM4.x : compatible paths using technique10 .

      • SM5.0 : new Direct3D 11 capabilities using technique11 .

        • vs_5_0 , hs_5_0 , ds_5_0 , gs_5_0 , ps_5_0 , cs_5_0 .

Shader

  • The syntax is very similar to FX10, however, technique11  is required when using functionality introduced by Direct3D 11, including SM5 shaders and interfaces.

  • Example: 

    technique10 OldHardware
{
    pass P0
    {
        // SM4-compatible shaders.
    }
}

technique11 NewHardware
{
    pass P0
    {
        // Can use Direct3D 11 / SM5 features.
    }
}
Executing

  • Same as FX10.

  • Example: 

    technique->GetPassByIndex(i)->Apply(0);

context->DrawIndexed(indexCount, 0, 0);
