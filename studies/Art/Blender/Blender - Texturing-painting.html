    • Roughness.

    • Specular.

    • Bump Map.

    • Normal Map.

    • Emissive Map.

    • Etc

  • Royal Skies - Using Custom Brushes .

    • The brush changes shape according to the texture used.

    • Usually black-and-white textures are used.

  • Royal Skies - Painting with a Stencil ("adesivos") .

  • Royal Skies - Painting with a Texture as Mask .

    • While the Mask is active, a visual wrap of the texture is applied around the object. Painting while it is active will 'draw' the mask texture onto the object.

Addons

  • Ucupaint

    • Free.

    • Ucupumar - Ucupaint normal map preview demo

    • Ryan King Art - Ucupaint

      • {3:38 -> 8:27} Basic.

    • About:

      • Each layer can affect multiple channels. This is very different from Paint System.

      • Channel list.

      • Preview of current channel.

      • Layers.

      • Preview of current layer.

      • Doesn't seem to have a brushes panel.

      • Layers can be procedural stuff:

        • Can add noise layers.

      • Apparently can do baking.

      • Tries to replace the shaders tab.

      • Usually adds a single node to the shader.

      • Overall, the layer system seems more powerful than Paint System's, and the addon seems quite more focused on layers than Paint System, which is a bit more broad.

  • Paint System

    • Creates group nodes automatically.

    • Tawan Sunflower - Paint System

    • Tawan Sunflower - Paint System 2.0 Patch Notes

    • Tawan Sunflower - Paint System 2.1 Patch Notes

    • Free.

    • About:

      • Each channel has it's own layers.

      • There's a brush and color panel, but they are simply copies of the existing blender panels and add not new functionality or workflow. A lot of things are missing, for example, you can't change the current brush in the panel.

      • There's actions.

      • Usually adds a single node to the shader.

  • HAS Paint Layers

    • Free.

  • Brushstroke Tools

    • Blender Studio - Brushstroke Tools

    • askNK - Brushstroke Tools showcase

    • Free.

    • The general idea seems to be around using the "grease tool" to guide the brushstrokes, keeping them non-destructive and editable.

    • It doesn't seem to care about exporting workflows, as the paint seems to always jump out of the object.

    • Each object has a list of brushstroke layers.

    • "Creates a lot of surface objects".

    • "The data for the scene to work is always included in the blend file, so it's not necessary to have the addon installed to visualize a scene made with addon".

    • Creates an insane geometry node tree.
